# BD渠道妈妈粉月度配额管理

基于最新 main 拉取后增加菜单 `bdQuota`，入口 `gift-admin-prototype.html?menu=bdQuota`，版本快照 v2.18。

## 本次范围
- 月份、活动编码、门店关键词、状态与配置来源查询，分页与结果导出。
- CSV 模板、上传解析、校验预览、整批确认覆盖。维度为活动编码 + 门店编码 + 月份。错误时整批拒绝，文件内重复拒绝，总额不能低于已使用量。
- 单店总额度调整及必填原因，修改前后额度、操作人、时间留痕。
- 接口准入，手工额度优先，无配置默认6；未匹配仅暂存，不形成可用额度。
- 参考项目 Excel 前12家门店；活动编码、接口匹配状态为演示，不代表生产接口结果。浏览器本地保存，未接业务接口或鉴权。

## 需确认
- PPT末尾新增门店示例写10，主体规则为6，当前采用6。
- PPT中月底导入的生效月份表述有歧义，当前支持显式指定当月或未来月份，历史月份不可导入。
- 跨月使用归属、降低额度策略、权限角色待明确；当前不低于已使用量。
- 当前原型 CSV 导入，正式系统若需 XLSX 应补充解析及服务端校验。
- 操作记录按月份、活动编码、门店编码查询；状态和来源仅作用于配额列表。

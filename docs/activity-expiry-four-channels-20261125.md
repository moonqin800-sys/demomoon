# 活动到期提醒四渠道原型

入口：activity-expiry-reminder.html；后台侧栏新增“活动到期提醒”链接。

- 短信：固定文案，不包含活动明细；示例短链进入手机 H5 只读列表，支持短链失效演示。
- 飞书：通知直接显示活动名称、编码、结束日期；点击后模拟后台登录，保留目标并返回明天到期查询。
- 邮件：主题和正文到期列表，点击后的登录及回跳同飞书。
- 页面查询：独立查询演示，支持名称/编码筛选；可进入现有后台并自动触发明天到期筛选。

默认北京时间每天14:00，次日结束日期当日23:59:59截止。通知无到期活动时不发送；列表查询显示空态。演示日期动态取北京时间次日，四条记录为合成样例，不代表真实到期活动。

本页不发送真实通知，不接短信短链服务、飞书、邮箱或真实账号系统，设置仅用于当前演示。短信 H5 暂按短链凭证访问，正式访问范围、有效期需要业务确认。登录输入任意演示信息即可，勿填写真实密码。

Chrome 检查通过：短信到H5、失效链接、飞书未登录回跳、邮件已登录直达、关键词筛选、无到期空态和390px页面无整体横向溢出。

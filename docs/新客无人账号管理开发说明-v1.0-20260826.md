# 新客无人账号管理开发说明

版本：v1.0  
日期：2026-08-26  
对应原型：`gift-admin-prototype.html`  
固定公网地址：https://moonqin800-sys.github.io/demomoon/gift-admin-prototype.html

## 1. 背景与目标

为满足新客无人门店账号的运营维护需求，后台新增「新客无人账号管理」一级菜单，支持按活动、用户、门店、状态、审核状态及时间条件查询账号，并支持列表导出和有效期编辑。

本期重点新增两个有效期字段：

- 开始时间
- 结束时间

目标是让账号生效区间可配置、可筛选、可导出、可追溯，减少人工改表成本。

## 2. 功能范围

本期建设范围包含：

- 新增一级菜单：新客无人账号管理
- 新增查询条件：开始时间、结束时间
- 新增列表字段：开始时间、结束时间
- 新增导出能力：导出结果包含开始时间、结束时间
- 新增编辑操作：仅允许编辑开始时间、结束时间
- 保留账号行内的启用/禁用、重置能力

不在本期范围：

- 账号新增、删除、批量导入的真实后端实现
- 门店、活动、用户基础资料的维护
- 审核流转的真实审批引擎

## 3. 菜单结构

| 菜单层级 | 菜单名称 | 页面说明 |
|---|---|---|
| 一级菜单 | 新客无人账号管理 | 新客无人门店账号台账管理 |

默认支持通过 `nav=newUserAccount` 直接定位页面。

## 4. 查询条件

### 4.1 查询区字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 活动名称 | 下拉框 | 按活动代码筛选账号 |
| 用户名称 | 输入框 | 支持登录名称、用户名称模糊查询 |
| 门店代码 | 输入框 | 支持门店代码模糊查询 |
| 状态 | 下拉框 | 启用、禁用 |
| 审核状态 | 下拉框 | 待审核、审核通过、审核驳回 |
| 创建时间 | 日期 | 按创建日期筛选 |
| 开始时间 | 日期 | 按账号生效开始日期筛选 |
| 结束时间 | 日期 | 按账号生效结束日期筛选 |

### 4.2 时间筛选规则

- 开始时间：查询 `start_at` 大于等于所选日期的账号
- 结束时间：查询 `end_at` 小于等于所选日期的账号
- 两个条件可同时生效

## 5. 列表字段

### 5.1 列表展示字段

| 字段 | 说明 |
|---|---|
| Id | 账号记录 ID |
| 活动code | 账号归属活动编码 |
| 活动名称 | 活动展示名称 |
| 门店code | 门店编码 |
| 门店名称 | 门店名称 |
| 用户code | 用户编码 |
| 登录名称 | 账号登录名 |
| 登录密码 | 账号密码 |
| 状态 | 启用 / 禁用 |
| 备注 | 账号说明 |
| 开始时间 | 账号生效开始时间 |
| 结束时间 | 账号生效结束时间 |
| 更新时间 | 最近一次修改时间 |
| 创建时间 | 记录创建时间 |
| 审核手机号 | 审核联系人手机号 |
| 审核时间 | 审核完成时间 |
| 审核状态 | 待审核 / 审核通过 / 审核驳回 |
| 操作 | 编辑、启用/禁用、重置 |

### 5.2 列表展示规则

- 开始时间、结束时间需完整展示到秒
- 列表导出与页面展示字段保持一致
- 空值展示 `-`

## 6. 编辑规则

### 6.1 编辑入口

列表行内点击「编辑」打开弹窗。

### 6.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|---|---|---|
| 开始时间 | 是 | 支持修改账号生效开始时间 |
| 结束时间 | 是 | 支持修改账号生效结束时间 |

### 6.3 只读字段

以下字段仅展示，不允许修改：

- 登录名称
- 门店代码
- 门店名称
- 状态
- 审核状态
- 备注

### 6.4 校验规则

- 开始时间、结束时间不能为空
- 结束时间不能早于开始时间
- 保存成功后刷新列表并更新更新时间

## 7. 导出规则

- 点击「导出(Excel)」导出当前筛选结果
- 导出内容包含开始时间、结束时间
- 导出格式建议使用 CSV 或 Excel 兼容格式
- 导出结果与列表字段顺序保持一致

## 9. 建议接口

| 接口 | 方法 | 说明 |
|---|---|---|
| /api/new-user-accounts | GET | 查询账号列表 |
| /api/new-user-accounts/export | GET | 导出账号列表 |
| /api/new-user-accounts/{id} | GET | 获取账号详情 |
| /api/new-user-accounts/{id} | PUT | 编辑开始时间、结束时间 |
| /api/new-user-accounts/{id}/status | PUT | 启用/禁用 |
| /api/new-user-accounts/{id}/reset-password | PUT | 重置密码 |

## 10. 权限建议

| 权限点 | 说明 |
|---|---|
| new_user_account:view | 查看列表、详情 |
| new_user_account:export | 导出列表 |
| new_user_account:update | 编辑开始时间、结束时间 |
| new_user_account:status | 启用 / 禁用 |
| new_user_account:reset | 重置密码 |

## 11. 验收标准

- 左侧菜单存在「新客无人账号管理」
- 查询区可按开始时间、结束时间筛选
- 列表中显示开始时间、结束时间
- 导出结果包含开始时间、结束时间
- 编辑弹窗仅允许修改开始时间、结束时间
- 保存后列表数据和更新时间同步刷新
